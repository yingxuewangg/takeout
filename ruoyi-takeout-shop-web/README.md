# 阿婆干饭社 · 商家管理端前端

基于 RuoYi-Vue 前端（Vue3 + Element Plus + Vite）二次开发的商家管理后台。

## 主要页面

- 数据看板（首页）：营业额/退款率概览、趋势（天/小时、客单价/退款率切换）、菜品排行与退款关联、分类占比、高峰时段、出餐效率
- 店铺信息：营业状态、配送费/起送价
- 菜品管理：分类/菜品/规格/口味/图片上传/售罄/每日限量
- 订单管理：状态机流转（接单/出餐/骑手已取餐/确认送达）、出餐取餐送达时间、小票打印
- 退款审核 / 留言管理 / 每日库存
- 新订单实时提醒（WebSocket + 浏览器语音播报）

## 启动

```bash
npm install
npm run dev          # 开发（代理 /dev-api → http://localhost:4121）
npm run build:prod   # 生产构建
```

登录账号 admin / admin123（后端若依体系）。WebSocket 提醒地址由 `.env.*` 的 `VITE_APP_WS_URL` 配置。
