# 阿婆干饭社 · 菜品与食材知识库

## 一、店铺简介

阿婆干饭社是一家主打家常盖饭与清淡小食的单店中餐馆，以"少油少盐、现炒现做"为特色。招牌菜品为阿婆牌爱心盖饭，选用当日新鲜五花肉与本地大米，慢火焖煮两小时，咸香入味。

## 二、清淡类菜品（适合肠胃不适、感冒、忌口人群）

感冒、喉咙痛、肠胃不适或需要忌口的顾客，建议选择清淡、易消化、少油少辣的菜品。店内适合的清淡选择：

1. **小份爱心盖饭（选不辣口味）**：分量适中、口味温和，米饭软糯易消化，适合胃口不佳时食用。
2. **清炒时蔬小食**：当季绿叶蔬菜快速清炒，少油少盐，补充维生素，适合感冒期间搭配主食食用。
3. **蒸蛋羹**：质地细嫩、口感清淡，蛋白质易吸收，适合喉咙痛或消化不良的顾客。
4. **白粥配小菜**：温和养胃，适合肠胃不适的早晨或夜宵。

## 三、食材说明

- **大米**：选用本地当季新米，颗粒饱满，蒸煮后软硬适中。
- **猪肉**：每日清晨由本地肉铺直供，冷藏配送，不使用冷冻肉。
- **蔬菜**：当日采购，不使用隔夜菜；时蔬类按季节调整品种。
- **食用油**：非转基因菜籽油，每道菜控制用油量。
- **辣椒**：可选辣度分为不辣、微辣、中辣、特辣，辣度为顾客下单时自选。

## 四、过敏原与忌口提示

- 菜品可能含有：大豆、鸡蛋、小麦（酱油、面粉类）、花生（部分小食）。
- 对上述食材过敏的顾客，请在下单备注中说明，厨房会尽量调整。
- 本店为家庭厨房式操作，无法完全隔离过敏原，严重过敏者请谨慎选择。

## 五、营业与配送

- 营业时间：09:00-21:00。
- 堂食：扫码点餐，需绑定桌号，出餐后凭桌号取餐。
- 外卖：配送费与起送价以店铺页面显示为准；配送范围覆盖店铺周边约 3 公里。
- 订单支付后商家接单开始制作；制作中如需取消请及时联系商家。

## 六、常见问题

- **能否不要辣？** 可以，下单时口味选择"不辣"即可。
- **能否少放盐？** 可以在订单备注中注明"少盐"，厨房会相应调整。
- **孕妇或老人适合吃什么？** 建议选择蒸蛋羹、白粥配小菜、清炒时蔬等清淡易消化的菜品。
- **有没有推荐给孩子的？** 蒸蛋羹与不辣的小份盖饭都比较适合小朋友，注意温度。
